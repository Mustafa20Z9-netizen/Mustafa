# Nexus · 多 AI 协同工作台

一个可双击运行的单文件 HTML 应用。输入一次任务，由 Gemini 拆解，Grok 与 ChatGPT 并行执行，再交给 Gemini 审核并形成最终答复。无需后端、构建工具或安装运行依赖。

## 在线使用

[打开 Nexus AI 伙伴工作台](https://nexus-companions-mustafa-20z9.mustafa20z9.chatgpt.site)（当前为所有者专用页面，需使用创建页面的 ChatGPT 账号登录）。也可以下载下方单文件在本机运行。不同网站地址和浏览器的配置独立保存，首次进入新地址需要重新填写 Key。

## AI 伙伴

- **星澜 / Gemini**：沉稳细致，负责理解目标、分派任务和最终审核。
- **逐风 / Grok**：好奇敏锐，负责梳理情报与信息依据。
- **灵犀 / ChatGPT**：耐心务实，负责推理、文案和代码。

原创 SVG 角色会随真实请求切换待命、思考、完成和异常状态。「协作现场」展示流程旁白，与模型原始内容分开；可关闭动效，并遵循系统的减少动态效果偏好。

## 开始使用

1. 下载仓库中的 `index.html`，用现代浏览器打开。
2. 想先了解流程，可点击「预览协作演示」。演示使用明确标注的预置内容，不调用 API，也不需要密钥。
3. 展开左侧模型配置，填写自己的 API Key、Base URL 和 Model。
4. 点击「测试连接」验证接口，再输入任务并点击「启动协同」。「已填写」仅表示配置有值；「连接已验证」表示模型已成功返回。

连接测试会发送一次极短聊天请求，真实任务通常包含两次 Gemini 请求及按分工产生的执行官请求，均按服务商规则计费。密钥不会随 HTML 文件提供。

## 默认模型与接口

| 角色 | 默认模型 | 默认接口 |
| --- | --- | --- |
| 总指挥 Gemini | `gemini-2.5-pro` | `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` |
| 情报官 Grok | `grok-2-latest` | `https://api.x.ai/v1/chat/completions` |
| 执行官 ChatGPT | `gpt-4o` | `https://api.openai.com/v1/chat/completions` |

全部使用 OpenAI 兼容的 Chat Completions 格式。Base URL 支持完整接口地址或 API 根地址；模型是否可用以服务商为准。当前未配置搜索工具，普通 Grok 聊天请求不保证实时联网检索。

## 工作台功能

- 实时展示分工与各模型状态，可在「执行记录」核查原始汇报。
- 未分派的角色自动跳过；单个执行官失败时，保留另一方结果并将失败记录交给总指挥。
- 支持停止、请求超时、Markdown 阅读、代码复制及 `.md` 下载。
- 本次会话保留最近 8 份已完成成果，可重新打开；刷新页面后清空。

## 数据与浏览器限制

API Key 和接口配置明文保存在当前浏览器的 `localStorage`，请求时发送到相应配置地址。请使用可信设备与服务；设置面板可清除保存的密钥。任务与成果仅保存在页面内存中。

浏览器直连要求服务端支持 CORS，`file://` 页面的来源通常为 `null`。跨域失败需使用允许该来源的可信接口；前端无法绕过服务端策略。停止操作仅中断浏览器等待，服务商仍可能继续处理并计费。应用不自动重试。

Tailwind CSS 与 marked 从 CDN 加载；失败时仍有内置样式与纯文本回退。完整模型调用需要网络和有效密钥。

## 验证

安装 Node.js 18 或更高版本后，在仓库根目录运行：

```sh
node tests/integration.cjs
```

测试仅使用内置模块和模拟接口，不需要密钥、不发起真实 API 请求，也不产生模型调用费用。覆盖调度、异常、取消竞态、连接测试、会话恢复及内容过滤；这些检查不代替真实接口连通性与浏览器视觉验收。
