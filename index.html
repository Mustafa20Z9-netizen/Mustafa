工作台设置与使用指南

01 / 配置模型

展开左侧模型项，填写 API Key。Base URL 可以是完整的 /chat/completions 地址，也可以是 API 根地址（例如 https://api.openai.com/v1）。设置自动保存；「已填写」不代表已连通。点击模型配置中的「测试连接」会发送一次极短聊天请求（按服务商规则计费），成功后显示「连接已验证」。

02 / 一次下达，自动执行

Gemini 拆解任务 → Grok 与 ChatGPT 并行执行 → Gemini 审核并交付。未分派的角色自动跳过。单个执行官失败仍会保留另一方结果，并在最终答复中披露缺口。你可以在「执行记录」查看完整分工和原始汇报。

03 / 浏览器与模型兼容

双击 HTML 即可运行。浏览器直连要求 API 支持 CORS；file:// 页面的来源通常为 null。跨域失败时，需换用允许该来源的可信中转。默认模型按原需求预填，若服务商已下线该模型，请换用支持的名称。普通聊天请求不自动获得实时搜索能力。

高级选项

停止只中断浏览器等待，服务商仍可能完成请求并计费。请求不会自动重试。

数据保存在什么地方？

密钥按你的要求明文保存在当前浏览器 localStorage，随请求发送至对应配置的接口。请使用可信服务。任务与成果仅保留在本次打开期间，刷新后清空。Tailwind 和 marked 从 CDN 加载；加载失败时，内置样式和纯文本回退仍可使用。
